## 3. Launching — `RunDevKit.bat` must run from its own folder

`RunDevKit.bat` contains a bug. It uses `%~dp0` (the script's own folder) for
the project path, but a bare **relative** path for the executable:

    start Engine\Binaries\Win64\UnrealEditor.exe "%~dp0\UE4\ConanSandbox.uproject" -ModDevKit

So it only works if the current directory is already the dev kit root. Run it
from anywhere else and it looks for the editor under *that* folder, finds
nothing, and the trailing `exit` closes the window before you see an error.
It fails completely silently.

Launch it like this instead, from any directory:

    Start-Process -FilePath "C:\Program Files\Epic Games\CEUE5Devkit\RunDevKit.bat" -WorkingDirectory "C:\Program Files\Epic Games\CEUE5Devkit"

To check whether it actually started:

    Get-Process UnrealEditor

The `-ModDevKit` flag the batch file passes is the part that matters — without
it **the mod menu does not appear at all**. Launching from the Epic Games
Launcher's Play button may skip it. If you ever open the editor and there's no
mod menu, that is why.

First launch takes a long time and may look frozen while it compiles shaders
and builds the DDC. Let it run.

## 6. Generate CookInfo.ini in the editor first

The cooker will not run without `GuildAccess\Local\CookInfo.ini`, which declares
which assets to cook. It is generated by the editor command **Choose Assets For
Cook**. Without it the build fails immediately with:

    Couldn't read CookInfo.ini, make sure one has been generated in editor
    with 'Choose Assets For Cook'

Redo this whenever the set of assets in the mod changes.

### Where the mod UI lives

Open it from **Window -> Conan Exiles Dev Kit**, at the very bottom of the
Window menu. (Its internal tab id is "Mods", but that is not the display
label.) That panel holds the Workshop
metadata (name, description, version, preview image), requested HTTP origins,
and these buttons: `Choose Assets For Cook`, `Compress .pak`,
`Open Source Folder`, `Open Output Folder`, `Compile All Modded Blueprints`.
Its mod action menu has `Create a new mod...` and `Select active mod`.

### How asset selection actually works

`Choose Assets For Cook` does not open a picker. It switches the **Content
Browser** into a mode where right-clicking offers:

- `Include asset(s) in cook` / `Exclude asset(s) from cook`
- `Include folder(s) in cook` / `Exclude folder(s) from cook`
- `Revert` - reverts a modified base asset to its original un-modded state.
  This matters in Phase 2 when we start overriding base assets.

An empty selection aborts the build:

    No modded files are selected to cook for the current mod '%s'. Aborting build

So a mod with zero assets cannot be cooked. Create `BPL_GuildAccess` first,
then include it. That library is required by the design anyway; see DESIGN.md
section 5.

Two gotchas when creating it:

- A Blueprint Function Library is **not** reachable via Blueprint Class ->
  Pick Parent Class. `BlueprintFunctionLibrary` appears in that tree but has no
  Select button, and double-clicking just expands its subclasses. Use the
  Content Browser's own right-click -> Blueprints -> Blueprint Function Library
  entry instead.
- Saved mod assets land in `GuildAccess\Local\`, **not** `GuildAccess\Content\`.
  `CookInfo.ini` lives there too. Despite the folder name this is real mod
  content and belongs in git.

## 7. Build headlessly

traps are documented in the script's `.NOTES` block, and both have already cost

passed to UAT must use forward slashes, because a trailing backslash escapes the
closing quote.

## 8. Install and verify in-game

1. Copy the `.pak` somewhere stable, e.g. `C:\ConanMods\GuildAccess.pak`.
2. Add the full path as a line in
   `C:\Program Files (x86)\Steam\steamapps\common\Conan Exiles\ConanSandbox\Mods\modlist.txt`.

   Every line in that file is currently commented out with `#`, so you are
   running vanilla. Keep it that way — a clean baseline is what we want for
   testing. Add only ours, uncommented.
3. Launch the game. The mod should appear in the mod list.

**That is the Phase 0 finish line.** An empty mod that loads.
